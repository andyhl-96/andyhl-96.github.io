Real-time Motion Planning

This project was developed in my time as an undergraduate researcher in the Purdue CoMMA Lab during the Spring 2025 semester. The purpose of this project was to create the first demonstration of real time motion planning on the lab's equipment, which consisted of the Franka Research 3 arm and Intel Realsense Camera.

WIP video:

I headed the development of a wrapper library to interface with the depth cameras to read pointcloud data of the environment which could then be fed to a motion planner. I also developed mechanisms to execute velocity trajectories on the FR3 synchronously as well as asynchronously for real-time capabilities. Additionally, I set up the design by which different portions of the project would interact.

This project has been concluded, having achieved satisfactory speed in demonstrations and robustness.
